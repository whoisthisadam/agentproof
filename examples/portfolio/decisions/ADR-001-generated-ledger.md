# ADR-001: the task ledger is generated, not written

- Status: accepted
- Date: 2026-08-10
- Decided by: Adam

## Context

The hand-written task list drifted within weeks: different spellings of the same status, missing rows, rows that grew into paragraphs. Filtering for open work stopped working.

## Decision

Every task has YAML front matter (`id`, `title`, `status`, `tier`, `product`, `created`, `updated`, `owner`). `tasks/README.md` is generated by `agentproof ledger`. CI runs `agentproof ledger --check` and `agentproof validate`.

## Consequences

- Status values are a fixed set; typos fail CI.
- Merge conflicts on the ledger are resolved by regenerating it.
- The ledger can't hold commentary. Context goes into the task.

## Alternatives considered

- An issue tracker: good for planning, but evidence and contracts belong next to the code and docs they describe.
- A hand-written ledger with a linter: still two sources of truth.
